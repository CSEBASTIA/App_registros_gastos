# App_registros_gastos
FinTrack Automator es una herramienta de gestión financiera que elimina el registro manual de egresos. El sistema utiliza técnicas de parsing y OCR para extraer datos clave de notificaciones de transacciones por correo y estados de cuenta bancarios. Centraliza montos, fechas y comercios en un dashboard dinámico para un control de gastos real.
