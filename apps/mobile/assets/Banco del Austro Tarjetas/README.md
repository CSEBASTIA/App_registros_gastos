# Banco del Austro · tarjetas de crédito

Frentes y logos oficiales organizados por tarjeta. Las fuentes son el [portal de solicitud de tarjetas de crédito](https://www.bancodelaustro.com/portal-tarjetas/servicios/solicitud-de-tarjetas), las páginas oficiales de [tarjetas Fútbol](https://www.bancodelaustro.com/tarjetas-futbol/tarjetas-credito), [Warner](https://www.bancodelaustro.com/tarjetas-warner/credito), [Visa Hyundai](https://www.bancodelaustro.com/portal-tarjetas/visa/credito/hyundai) y [Visa Mundial](https://www.bancodelaustro.com/portal-tarjetas/visa/credito/mundial).

Incluye Visa y Mastercard clásicas, Visa Hyundai/KIA/Mundial, Mastercard Fútbol, y diseños Visa/Mastercard Warner y Game of Thrones. Se dejaron fuera tarjetas de débito, imágenes de personas y promociones que no muestran un frente de tarjeta. Los nombres de archivo coinciden con los ids del catálogo móvil.

El logo oficial del banco está en `logo-banco-del-austro.png`; una copia PNG se usa como logo de respaldo en `apps/mobile/assets/logos/banco_austro.png`.
